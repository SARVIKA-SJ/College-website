<h1>College Website Overview</h1>
<p>This is an informational website created for BMS Educational Trust – College of Commerce and Management. The website includes a modern navigation bar, dropdown menus, background images, and multiple pages such as About, Courses, People, Events, and Contact.</p>
<h2>Features</h2>
<ul>
<li>Responsive Navigation Bar: Clean top menu with dropdowns.</li>
<li>Background Images: Enhances the visual layout.</li>
<li>College Logo Section: Circular logo with institution title.</li>
<li>Multi-page Structure: Separate pages for About, Courses, Faculty, Events, and more.</li>
<li>Simple & Clean UI: Designed for readability and ease of use.</li>
</ul>
<h2>Technologies Used</h2>
<ul>
<li>Frontend: HTML, CSS</li>
<li>Styling: CSS3 (custom styles, gradients, hover effects)</li>
<li>No Frameworks Needed: Pure HTML/CSS for easy hosting and maintenance</li>
</ul>
<h2>Installation</h2>
<h3>1. Clone the repository</h3>
<p>git clone https://github.com/your-username/college-website.git</p>
<h3>2. Navigate to the project folder</h3>
<p>cd college-website</p>
<h3>3. Open the website</h3>
<p>Just open homepage.html in any browser.</p>
<h2>Usage</h2>
<ul>
<li>Browse through all navigation links.</li>
<li>Access dropdowns under People, Courses Offered, and Happenings.</li>
<li>View sections such as Founders, Principal, Faculty, Curriculum, Events, and Contact.</li>
</ul>
