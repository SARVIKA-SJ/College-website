<ul>
<li>Responsive Navigation Bar: Clean top menu with dropdowns.</li>

<li>College Logo Section: Circular logo with institution title.</li>
<li>Multi-page Structure: Separate pages for About, Courses, Faculty, Events, and more.</li>
<li>Simple & Clean UI: Designed for readability and ease of use.</li>
